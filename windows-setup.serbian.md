# Подешавање video-subtitler-а на Windows-у

Ћао 👋 — прати сваки корак по реду. Не прескачи кораке. Ако нешто
на твом екрану не изгледа онако како је овде описано, **стани и
пошаљи Танчу снимак екрана** пре него што наставиш.

Шта ти треба:

- Лаптоп са Windows 10 или Windows 11.
- Интернет конекција (само током инсталације; после тога ради и
  без интернета).
- Око **30–60 минута** — већину тог времена само чекаш.
- Око **3 GB слободног простора на диску**.

Ово радиш **само једном**. Кад проради, прављење титлова је просто
превлачење видеа мишем.

> 🇬🇧 English version: [WINDOWS-SETUP.md](WINDOWS-SETUP.md)

---

## Корак 1 — Отвори Chrome и преузми алат

1. **Отвори Chrome.** (Edge или Firefox такође раде — користи онај
   који обично користиш.)

2. У адресну линију на врху упиши или налепи ово и притисни **Enter**:

   <https://github.com/smarkovik/video-subtitler>

3. Видећеш страницу са списком фајлова као што су `README.md`,
   `setup.bat`, `src`, `docs`, итд.

4. У **горњем десном углу** списка фајлова, пронађи зелено дугме на
   ком пише **"Code"** са малом иконицом `<>`. Кликни на њега.

5. Појавиће се мали мени. На **дну тог менија** налази се линк
   **"Download ZIP"**. Кликни га.

6. Почеће да се преузима фајл под именом
   **`video-subtitler-main.zip`**. Мали је, испод 1 MB. Сачекај да
   се преузимање заврши.

---

## Корак 2 — Распакуј ZIP

Windows не може ништа да покрене из самог ZIP фајла — прво мораш
да га распакујеш.

1. Отвори **File Explorer** (жута иконица фасцикле на траци
   задатака, или притисни **Windows + E**).

2. У левој страни прозора кликни **"Downloads"** (Преузимања).

3. Пронађи **`video-subtitler-main.zip`**, **десни клик** на њега,
   и изабери **"Extract All..."** (Распакуј све...).

4. Појавиће се прозор који те пита где да распакује. Кликни
   **"Browse..."** (Прегледај), у левом панелу изабери **"Desktop"**
   (Радна површина), кликни **"Select Folder"** (Изабери фасциклу),
   па онда **"Extract"** (Распакуј).

5. Отвара се нови File Explorer прозор. Налазиш се у фасцикли по
   имену `video-subtitler-main` која садржи **још једну** фасциклу
   истог имена. Двоструки клик да уђеш у унутрашњу.

6. Сада би требало да видиш фајлове укључујући:

   ```
   setup.bat
   ui.bat
   run.bat
   README.md
   src/
   docs/
   ```

   **Не затварај овај File Explorer прозор** — биће ти потребан за
   следећи корак.

---

## Корак 3 — Покрени setup.bat (спори корак)

Овај корак инсталира Python, ffmpeg, и преузима говорни модел од
1.5 GB. Рачунај на **5–15 минута** зависно од брзине интернета.

1. **Двоструки клик на `setup.bat`**.

2. **Могући искачући прозор**: Windows може приказати поруку
   *"Windows protected your PC"* (Windows је заштитио твој рачунар)
   на плавој позадини. Ако је видиш:

   - Кликни мали линк **"More info"** (Више информација).
   - Појавиће се ново дугме: **"Run anyway"** (Свеједно покрени).
     Кликни га.

3. Отвара се црни прозор. Паузира на поруци **"Press any key to
   continue..."** (Притисни било који тастер). Притисни размакницу.

4. Прозор исписује заглавља напретка:

   - `==> Checking prerequisites`
   - `==> Installing Python and ffmpeg`
   - `==> Verifying ffmpeg has subtitle support`
   - `==> Creating Python virtual environment`
   - `==> Installing Python dependencies`
   - `==> Downloading Whisper-medium speech model (~1.5 GB)`

5. **Могући искачући прозори**: током инсталације Python-а и
   ffmpeg-а, Windows ће можда питати "Do you want to allow this app
   to make changes?" (Желиш ли да дозволиш овој апликацији да
   изврши промене?). Сваки пут кликни **"Yes"** (Да).

6. **Преузимање модела је најспорији део.** Прозор ће изгледати
   замрзнут 5–15 минута. **Није замрзнут — преузима фајл.** Не
   затварај га. Не притискај ништа. Само сачекај.

7. Кад се све заврши, видећеш:

   ```
   ============================================================
     Setup complete. You can close this window.

     To subtitle a video: drag it onto run.bat
   ============================================================
   ```

   Притисни било који тастер да затвориш прозор. **Инсталација је
   готова заувек** — никада више не мораш да покрећеш `setup.bat`.

---

## Корак 4 — Отвори алат

1. У истој фасцикли, пронађи **`ui.bat`**.

2. **Двоструки клик на `ui.bat`**.

3. Отвара се црни прозор са текстом:

   ```
   Starting the video-subtitler UI...
   Your browser should open in a moment.
   Leave this window open while you work. Close it to stop the server.
   ```

4. После 2–3 секунде, **прегледач се отвара сам** на страници под
   насловом "video-subtitler" са великим испрекиданим оквиром на
   ком пише **"Drop a video here"** (Спусти видео овде).

5. ⚠️ **Не затварај црни прозор.** То је сервер који ради —
   затварање прозора га зауставља и страница престаје да ради.

Ако се прегледач не отвори сам, отвори га ручно, упиши
**`localhost:8765`** у адресну линију, и притисни Enter.

---

## Корак 5 — Сад отпреми видео превлачењем мишем

Превуци свој видео фајл из File Explorer-а на испрекидани оквир у
прегледачу.
